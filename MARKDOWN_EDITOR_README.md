# Markdown-редактор для комментариев

## Описание

Добавлен полноценный Markdown-редактор на страницу вопросов с предварительным просмотром. Редактор использует библиотеку [SimpleMDE](https://github.com/sparksuite/simplemde-markdown-editor) - популярный и стабильный JavaScript Markdown редактор с встроенной панелью инструментов и предварительным просмотром.

## Функциональность

### Интерфейс редактора
- **SimpleMDE редактор** - полнофункциональный Markdown редактор с панелью инструментов
- **Предварительный просмотр** - встроенный предварительный просмотр с подсветкой синтаксиса
- **Режимы просмотра** - обычный, предварительный просмотр, бок о бок, полноэкранный
- **Горячие клавиши** - встроенные сочетания клавиш для быстрого форматирования

### Поддерживаемые Markdown элементы
- Заголовки (`#`, `##`, `###`)
- **Жирный текст** и *курсив*
- Списки (маркированные и нумерованные)
- Ссылки и изображения
- Блоки кода и инлайн код с подсветкой синтаксиса
- Цитаты
- Таблицы

### Автоматическое сохранение
- При редактировании текста автоматически сохраняется черновик с задержкой 1 секунда
- Индикатор "Сохранение..." показывает статус сохранения

### Применение черновика
- Кнопка "Применить" применяет черновик как основной текст
- После применения статус комментария обновляется

### Загрузка контента
- По умолчанию загружается черновик (если есть)
- Если черновика нет, загружается основной текст
- Если ничего нет, редактор пустой

## GraphQL запросы

**Примечание:** ID вопросов имеют тип `Long` (числовой), поэтому в запросах используется `Long!` вместо `String!`.

### Получение комментария
```graphql
query Comment($id: Long!) {
  comment(id: $id) {
    id
    status
    draft {
      created
      updated
      text {
        lang
        text
      }
    }
    text {
      created
      updated
      text {
        lang
        text
      }
    }
  }
}
```

### Сохранение черновика
```graphql
mutation Draft($id: Long!, $draft: String!) {
  draft(id: $id, draft: $draft) {
    id
    status
    draft {
      created
      updated
      text {
        lang
        text
      }
    }
  }
}
```

### Применение черновика
```graphql
mutation ApplyDraft($id: Long!) {
  applyDraft(id: $id) {
    id
    status
    text {
      created
      updated
      text {
        lang
        text
      }
    }
  }
}
```

## Использование

1. Выберите вопрос из списка слева
2. Внизу страницы появится SimpleMDE редактор
3. Используйте панель инструментов для быстрого форматирования
4. Переключайтесь между режимами: обычный, предварительный просмотр, бок о бок
5. Используйте горячие клавиши для быстрого форматирования
6. Текст автоматически сохраняется как черновик
7. Нажмите "Применить" чтобы сохранить как основной текст
