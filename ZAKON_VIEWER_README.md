# Компонент просмотра закона

## Описание

Добавлен новый компонент `ZakonViewerComponent` для отображения текста закона о безопасности дорожного движения на странице вопросов. Компонент размещен справа от содержимого вопроса и предоставляет полный функционал для работы с текстом закона.

## Функциональность

### Основные возможности:
- **Отображение текста закона** с поддержкой markdown-разметки
- **Переключение языков** между сербским и русским
- **Поиск по тексту** с поддержкой обоих языков
- **Фильтрация по главам** закона
- **Копирование ссылок** на конкретные параграфы
- **Пагинация** для удобного просмотра больших объемов текста

### Структура данных:
Каждый элемент закона содержит:
- `chapter` - номер главы
- `chlan` - номер статьи  
- `paragraph` - номер параграфа
- `sr` - текст на сербском языке (markdown)
- `ru` - текст на русском языке (markdown)
- `isTitle` - флаг заголовка

### Ссылки:
Ссылки генерируются в формате: `zakon?chapter=I&chlan=2&paragraph=0`

## Компоненты

### ZakonService (`src/app/services/zakon.service.ts`)
Сервис для работы с данными закона:
- Загрузка данных из `parsed_zakon.json`
- Поиск по тексту
- Фильтрация по главам/статьям/параграфам
- Генерация ссылок

### ZakonViewerComponent (`src/app/components/zakon-viewer/`)
Основной компонент просмотра:
- Отображение текста с markdown-разметкой
- Панель управления (язык, поиск, фильтры)
- Результаты поиска с подсветкой
- Пагинация

## Интеграция

Компонент интегрирован в существующую страницу вопросов:
- Добавлен в правую панель макета
- Использует Material Design компоненты
- Адаптивная верстка для мобильных устройств

## Стили

Стили написаны с учетом требований:
- Используются только Material Design цвета и шрифты
- Определяется только позиционирование элементов
- Адаптивная верстка для разных размеров экрана

## Использование

1. Откройте страницу вопросов
2. Выберите любой вопрос из списка
3. Справа появится панель с текстом закона
4. Используйте кнопки управления для:
   - Переключения языка
   - Поиска по тексту
   - Фильтрации по главам
   - Копирования ссылок на параграфы

## Технические детали

- Используется библиотека `ngx-markdown` для отображения markdown
- HTTP клиент настроен в `app.config.ts`
- Компонент является standalone
- Поддерживается SSR (Server-Side Rendering)
